# CleanCo - Supabase Backend

This project uses a Node.js + Express backend with Supabase as the only storage layer. Products, settings, contact messages, and uploaded images are stored in Supabase.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Configure Supabase credentials using environment variables:

```bash
export SUPABASE_URL="https://your-project.supabase.co"
export SUPABASE_SERVICE_ROLE_KEY="your-service-role-key"
export SUPABASE_BUCKET="uploads"
```

You can also copy `supabase.config.example.json` to `supabase.config.json` for local development.

3. Start the server:

```bash
npm start
```

The server runs at `http://localhost:3000` by default.

## API

- `GET /api/products` - list products
- `POST /api/products` - add a product
- `PUT /api/products/:id` - update a product
- `DELETE /api/products/:id` - delete a product
- `GET /api/settings` - get settings
- `POST /api/settings` - update settings
- `GET /api/contacts` - list contact submissions
- `POST /api/contacts` - submit a contact message
- `DELETE /api/contacts/:id` - delete a contact message

## Supabase Tables

Create these tables in Supabase before running the app:

```sql
create table if not exists products (
  id bigint generated by default as identity primary key,
  cat text,
  badge text,
  brand text,
  name text,
  "desc" text,
  img text,
  price numeric default 0,
  "priceOld" numeric,
  rating numeric default 0,
  reviews integer default 0,
  created_at timestamptz default now()
);

create table if not exists settings (
  key text primary key,
  value jsonb
);

create table if not exists contacts (
  id bigint generated by default as identity primary key,
  name text,
  email text,
  phone text,
  subject text,
  message text,
  created_at timestamptz default now()
);
```

Create a public Supabase Storage bucket named `uploads`, or set `SUPABASE_BUCKET` to the bucket name you want to use.
